Referencia de la API REST

🧪 Credenciales de prueba

Puedes usar el usuario api@generadordata.com y la contraseña generadordata para generar tu token vía curl.

curl -X POST {baseUrl}/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"api@generadordata.com","password":"generadordata"}'

🔑 Autenticación

Todos los endpoints requieren Bearer Token. Obtén tu token realizando login en la API.

POST /api/login
→ { "token": "eyJhbGciOi..." }

📄 Generación de Documentos

Genera DNI, NIF, NIE, CIF y SSN aleatorios válidos. Parámetro result define cuántos generar (máx. 20).

GET /api/generate-dni?result=2
→ ["12345678A", "87654321B"]

GET /api/generate-cif-by-type?result=3&type=B
→ ["B12345678", "B87654321", "B11223344"]

✅ Validar documento

Valida cualquier documento español con document y, opcionalmente, type (si se omite, se auto-detecta).

GET /api/validate-document?document=12345678Z&type=DNI
→ { "document": "12345678Z", "type": "DNI", "message": "VALIDO" }

💳 Datos Financieros

Genera IBAN, cuenta bancaria (CCC) y números de tarjeta (VISA/MASTERCARD/AMEX) válidos.

GET /api/generate-iban
→ { "iban": "ES7921000813610123456789", "formatted": "ES79 2100 0813 6101 2345 6789" }

GET /api/generate-tarjeta?type=VISA
→ { "card_number": "4532123456789010", "expiry": "08/28", "cvv": "123" }

✅ Validar IBAN

Valida un IBAN español con iban (los espacios se ignoran).

GET /api/validate-iban?iban=ES79+2100+0813+6101+2345+6789
→ { "valid": true, "message": "VALIDO" }

⚡ Generar CUPS

Genera códigos CUPS de electricidad o gas indicando tipo, distribuidora (4 dígitos), cantidad (máx. 100) e incluirSufijo.

POST /api/cups/generate
{"tipo":"electricidad","distribuidora":"0021","cantidad":3,"incluirSufijo":false}
→ { "cups": ["ES0021123456789012AB", "ES0031987654321098CD"] }

✅ Validar CUPS

Valida el formato y letras de control de un código cups.

POST /api/cups/validate
{"cups":"ES0021000000000001RK"}
→ { "valido": true, "detalles": {"pais":"ES","distribuidora":"0021", ...} }
