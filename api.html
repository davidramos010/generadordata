Generación de Documentos vía API REST

🧪 Credenciales de prueba

Puedes usar el usuario api@generadordata.com y la contraseña generadordata para generar tu token vía curl.

curl -X POST {baseUrl}/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"api@generadordata.com","password":"generadordata"}'

📝 Registro de nuevo usuario

Crea un nuevo usuario mediante el endpoint POST /api/register.

curl -X POST {baseUrl}/api/register \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"name":"John Doe","email":"user@example.com","password":"Abc123456","password_confirmation":"Abc123456"}'

🔑 Autenticación

Todos los endpoints requieren Bearer Token. Obtén tu token realizando login en la API.

POST /api/login
→ { "token": "eyJhbGciOi..." }

📄 DNI — Documento Nacional de Identidad

Genera DNI aleatorios válidos. Parámetro result define cuántos generar (máx. 20).

GET /api/generate-dni?result=2
→ ["12345678A", "87654321B"]

📄 NIF — Número de Identificación Fiscal

Genera NIF aleatorios válidos (8 dígitos + letra de control).

GET /api/generate-nif?result=2
→ ["12345678A", "87654321B"]

📄 NIE — Número de Identificación de Extranjero

Genera NIE aleatorios válidos (X/Y/Z + 7 dígitos + letra de control).

GET /api/generate-nie?result=2
→ ["X1234567A", "Y7654321B"]

🏢 CIF — Código de Identificación Fiscal

Genera CIF válidos filtrados por tipo de entidad con type (A–W).

GET /api/generate-cif-by-type?result=3&type=B
→ ["B12345678", "B87654321", "B11223344"]
