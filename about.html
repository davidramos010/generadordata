Nuestra misión

Nuestra plataforma está dedicada a la generación de datos de prueba para desarrolladores y testers. El contenido y los datos generados en este sitio son exclusivamente para fines de prueba y desarrollo, y no deben ser considerados como información real.

Nuestros servicios

🧩 Más generadores

DNI, NIF, NIE y CIF, cuentas bancarias con IBAN y CCC, tarjetas de prueba VISA, Mastercard y AMEX, y códigos CUPS de luz y gas. Todos con sus dígitos y letras de control correctos.

⚙️ API REST

Los mismos generadores desde tu propio código, con autenticación por token y ejemplos curl listos para copiar. Ver documentación de la API →

🗄️ Datos masivos

Hasta 20 resultados por petición en la web y hasta 100 códigos CUPS por llamada en la API. El historial de cada generador se exporta a CSV con un clic.

🔒 Seguridad

Todos los datos son aleatorios: no corresponden a personas, cuentas bancarias, tarjetas ni suministros reales, y no se almacena ningún resultado generado.
